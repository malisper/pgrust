pgrust passes 100% of the Postgres regression tests

pgrust reaches full PostgreSQL regression and isolation test compatibility.

Michael Malis · June 25, 2026

pgrust is a Postgres rewrite in Rust that I’ve been working on with my friend Jason Seibel. It targets compatibility with Postgres 18.3, passes the PostgreSQL regression tests, and now also passes the isolation tests.

It is disk compatible with Postgres and and can boot from an existing Postgres 18.3 data directory. It is not production-ready yet, not performance optimized yet, and not compatible with existing Postgres extensions. The goal is to make Postgres easier to change from the inside: keep Postgres behavior as the oracle, use Rust to make the codebase easier to work on, and use AI-assisted programming to explore deeper server changes.
