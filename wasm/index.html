About

pgrust is an experimental rewrite of PostgreSQL in Rust — not a toy clone, but an attempt to track Postgres behavior closely enough to become a base for deeper experiments.

It already passes all of PostgreSQL's default regression suite. The current focus is stability, bug-bashing, and closing the performance gap.
